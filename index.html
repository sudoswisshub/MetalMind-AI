Fig. 04 Code

Code comes highlighted. SVG comes drawn.

Replies set code in monospace with syntax colouring for Swift, Python, JavaScript, TypeScript, C, Java, Kotlin and LaTeX, in four code themes. An SVG or HTML block gets a Preview button: the drawing is rendered on the device, with scripts off and no network, and opens full screen with pinch zoom.

  • Copy one block, or Copy Code Only from a whole reply.
  • Slightly broken SVG from a small model is repaired before it is drawn.
  • Attach code files and ask about them, like any document.

Fig. 09–12 Under the page

        
The parts you never see.

      

      
Running a language model on a phone is mostly a question of memory. Four things the engine does about it, each sketched in motion.

    

    

      

        
09 Turns

        

          Turn 1
          

          
held in the cacheread this turngenerated

        

        
Only what is new gets read.

        
Each turn the whole chat is rendered exactly as the model was trained on it. The part the cache already holds is skipped, and only the rest is fed in.

      

      

        
10 Draft models

        

          
Draft
0.6B

          
Main
4B

          
proposedacceptedmain model's own

        

        
A small model guesses ahead.

        
For a few larger models, a much smaller one of the same family proposes a handful of tokens and the larger model checks them in one pass. The output is identical to running the main model alone.

      

      

        
11 Memory-aware prefill

        

          
memory floormemory left

          

          

          prompt, read in chunks
        

        
Long prompts, in chunks that fit.

        
Reading a long prompt is when a phone is most likely to end the app. So it is read in chunks sized from the memory the app has left, each using at most half the headroom above the device's memory floor.

      

      

        
12 Session cache

        

          
chat openchat left · cache written to diskchat reopened · context restored

          

            
chat

            
            
disk

          

        

        
Chats keep their place.

        
Leave a chat and the model's working memory of it is written to disk. Reopen it with the same model and the full context comes back, instead of a clipped transcript being read again.

      

    

    
Settings › Performance keeps per-model medians measured on your own device: time to first token, generation speed, prompt-processing speed and peak memory. Prompts and replies are never recorded.
